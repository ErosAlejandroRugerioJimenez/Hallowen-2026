PON TUS FOTOS AQUÍ

Formatos: JPG, JPEG, PNG, WebP, AVIF y TIFF.
No necesitas convertirlas ni reducirlas. Se conservan los originales.
Puedes usar subcarpetas por año, por ejemplo: 2024/01-desfile.jpg.
También sirve: 2023-concurso.jpg. El año es opcional; no se inventará.

Después de agregar fotos:
  npm run gallery:import

También se importan al ejecutar npm run dev o npm run build.
Si el servidor ya estaba abierto, ejecuta gallery:import para actualizarlo.
Las versiones WebP se generan en public/images/recuerdos.
Evita incluir fotos que no quieras mostrar públicamente.
